Aprendí haciendo pequeños videojuegos, trasteando con Unity usando C#. Luego conseguí mi primer trabajo como desarrollador web y desde entonces no he parado de aprender y mejorar en este mundo: buenas prácticas, nuevos lenguajes, paradigmas y formas de ser eficiente en mi trabajo. Proyectos


Aquí mostraré un listado de algunas descripciones de proyectos que haya realizado tanto en mi trabajo como en otros ámbitos.


  • Una aplicación robo-advisor para inversión indexada con alto nivel de seguridad debido a tratarse del sector banca, concurrencia y alta carga de trabajo asíncrono.

  • Una API para un marketplace multitenant para venta de productos alimenticios B2B y B2C hecha en Symfony. Compuesta por una base de datos relacional, proyecciónes a Redis y a Elasticsearch, comunicación por eventos utilizando RabbitMQ y utilizando Domain Driven Design.

  • Marketplace multitenant para una gran empresa con alto volumen de peticiones. Con la creación de un tenant dentro de la plataforma se levanta una infrastructura independiente en tiempo de ejecución: Un entorno distribuido con Kubernetes, bases de datos, proyecciones, motor de búsqueda, etc.

  • Un Ecommerce para una empresa de producto, en la que estaban incluidos el formulario de compra, la conexión con la pasarela de pago y un CRM donde se gestionan facturas, pedidos, stock de productos, envíos de email, promociones y otras funcionalidades.

  • Una web de gestión de cursos dirijida al arbitraje en el mundo del fútbol donde se puede crear formación para mostrarla al público, gestionar las inscripciones, los pagos y sincronizarse con otro sistema Mooc externo.

  • Una web para una federación de árbitros internacional que permite la gestión de torneos, un cortador de vídeos para extraer clips de los partidos y su posterior análisis por parte de los usuarios y un módulo de formación para árbitros.

  • Un gestor de respositorios de imágenes categorizadas por etiquetas y un sistema para compartir dichos repositorios a clientes con diferentes permisos y calidades de imagen.

  • Una demo web hecha con React y Three.js, que consiste en un simulador de contaminación atmosférica en 2D. Una serie de variables se reflejan en la pantalla que muestra tanto el número de coches, como las partículas de contaminación, como se ven afectada por el viento y por la frecuencia de precipitaciones, además de gráficas que muestran los valores numéricos.
